## `vp outdated -- -h`

应显示 yarn upgrade-interactive 帮助信息

```

打开升级界面

━━━ 用法 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

打开升级窗口
  $ yarn upgrade-interactive
```
