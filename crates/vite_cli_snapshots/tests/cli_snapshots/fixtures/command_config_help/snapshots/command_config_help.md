# 命令配置帮助

## `vp config -h`

```
VITE+ - 面向 Web 的统一工具链

用法：vp config [选项]

为当前项目配置 Vite+（钩子 + 代理集成）。

选项：
  --hooks-dir <path>  自定义钩子目录（默认：.vite-hooks）
  --no-hooks          跳过钩子安装
  --no-agent          跳过更新编码代理指令
  -h, --help          显示帮助信息

环境变量：
  VITE_GIT_HOOKS=0  跳过钩子安装

文档：https://viteplus.dev/guide/commit-hooks
```
