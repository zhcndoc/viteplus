# command_owner_pnpm10

## `vp pm owner --help`

应显示帮助信息

```
VITE+ - Web 的统一工具链

用法：vp pm owner <COMMAND>

管理软件包所有者

命令：
  list  列出软件包所有者 [别名：ls]
  add   添加软件包所有者
  rm    移除软件包所有者

选项：
  -h, --help  显示帮助信息

文档：https://viteplus.dev/guide/install
```

fengmk2 <fengmk2@gmail.com>
