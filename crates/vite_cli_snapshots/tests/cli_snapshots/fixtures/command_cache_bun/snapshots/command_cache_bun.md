# command_cache_bun

## `vp pm cache --help`

应显示帮助信息

```
VITE+ - Web 的统一工具链

用法：vp pm cache <SUBCOMMAND> [-- <PASS_THROUGH_ARGS>...]

管理包缓存

参数：
  <SUBCOMMAND>            子命令：dir、path、clean
  [PASS_THROUGH_ARGS]...  其他参数

选项：
  -h, --help  打印帮助信息

文档：https://viteplus.dev/guide/install
```

## `vp pm cache dir`

应显示缓存目录


## `vp pm cache path`

应显示缓存路径（`dir` 的别名）
