# command_view_npm10

## `vp pm view testnpm2 dist.tarball`

应查看 testnpm2 软件包信息

```
http://127.0.0.1:<port>/testnpm2/-/testnpm2-1.0.1.tgz
```

## `vp pm info testnpm2 dist.tarball`

应该将 info 别名指向 view

```
http://127.0.0.1:<port>/testnpm2/-/testnpm2-1.0.1.tgz
```

## `vp pm show testnpm2 dist.tarball`

应显示用于查看的别名

```
http://127.0.0.1:<port>/testnpm2/-/testnpm2-1.0.1.tgz
```
