# command_env_clean

## `vp env clean`

清理隔离的 Vite+ 缓存

```
VITE+ - Web 的统一工具链

✓ 已移除 0 个 Node.js 运行时
✓ 已移除 0 个包管理器安装
```

仅清理 Node.js 运行时

```
VITE+ - The Unified Toolchain for the Web

✓ Removed 0 Node.js runtimes
```

```
✓ Removed 0 package manager installs
```
