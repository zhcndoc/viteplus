# nested_yarn_resolves_project_version

## `vpt json-edit package.json packageManager yarn@4.12.0`


## `vp env on yarn`


## `npx --offline --call 'yarn --version'`

嵌套 shim 首次使用时会安装项目 Yarn


## `npx --offline --call 'yarn --version'`

npx 无需系统 Yarn 即可解析项目 Yarn

```
4.12.0
```

## `npx --offline --call 'yarnpkg --version'`

Yarn 别名会解析到相同的项目版本

```
4.12.0
```
