# pm_dedupe_bun_1_4

## `vp install -- --silent`

安装以创建锁文件

```
VITE+ - The Unified Toolchain for the Web
```

## `vp dedupe`

bun 1.4 直接运行 bun dedupe

```
bun dedupe <version> (<hash>)
🎉 No duplicates — checked 2 packages, every one already resolves to a single version [<duration>]
```

## `vp dedupe --check`

检查模式会报告结果，但不会更改锁文件

```
bun dedupe <version> (<hash>)
🎉 No duplicates — checked 2 packages, every one already resolves to a single version [<duration>]
```
