# vp pm pkg

读取和更新 `package.json` 字段，无需手动编辑清单。

```bash
vp pm pkg get name version
vp pm pkg set scripts.check='vp check'
vp pm pkg set private=true --json
vp pm pkg delete scripts.old
vp pm pkg fix
```

## 选项

- `get [key...]` 读取字段；未指定键时读取整个清单。`--json` 请求原生 JSON 输出。
- `set <key=value...>` 写入字段。`--json` 会将值解析为 JSON，因此布尔值、数字、数组和对象不会被保存为字符串。
- `delete <key...>` 移除字段。
- `fix` 请求包管理器修正常见清单错误。

字段路径和规范化方式遵循原生包管理器。包含方括号或 shell 敏感字符的路径请加引号。

### `get`

| 选项      | 说明                   | 备注                                |
| -------- | ---------------------- | --------------------------------- |
| `--json` | 以 JSON 格式输出。      | 输出保留原生 schema。             |

### `set`

| 选项      | 说明                                 | 备注                                                                        |
| -------- | ------------------------------------ | ------------------------------------------------------------------------- |
| `--json` | 写入前将值解析为 JSON。               | 解析布尔值、数字、数组和对象，而不是将它们保存为字符串。                     |

### `delete`

没有该命令专用的选项。

### `fix`

没有该命令专用的选项。

## 兼容性

### `get`

- **npm：** 7.20.0 或更高版本使用 `npm pkg get`。较早版本会警告并跳过。
- **pnpm：** 11.3.0 或更高版本使用 `pnpm pkg get`。较早版本会警告并跳过。
- **经典版 Yarn：** 没有对应命令。会警告并成功退出，不执行操作。
- **现代版 Yarn：** 没有对应命令。会警告并成功退出，不执行操作。
- **Bun：** 1.2.19 或更高版本使用 `bun pm pkg get`。较早版本会警告并跳过。

| 选项      | npm             | pnpm            | 经典版 Yarn   | 现代版 Yarn  | Bun             | 备注  |
| -------- | --------------- | --------------- | ------------ | ----------- | --------------- | ----- |
| `--json` | 7.20.0 或更高版本 | 11.3.0 或更高版本 | 不支持      | 不支持       | 1.2.19 或更高版本 |    |

### `set`

- **现代版 Yarn：** 没有对应命令。会警告并成功退出，不执行操作。

### `delete`

- **npm：** 7.20.0 或更高版本使用 `npm pkg delete`。较早版本会警告并跳过。
- **pnpm：** 11.3.0 或更高版本使用 `pnpm pkg delete`。较早版本会警告并跳过。

### `fix`

- **npm：** 9.8.0 或更高版本使用 `npm pkg fix`。较早版本会警告并跳过。

- **经典版 Yarn：** 没有对应命令。会警告并成功退出，不执行操作。
- **现代版 Yarn：** 没有对应命令。会警告并成功退出，不执行操作。
- **Bun：** 1.2.19 或更高版本使用 `bun pm pkg fix`。较早版本会警告并跳过。

低于所述版本要求时会发出警告并成功退出，不运行操作。不支持的包管理器或版本不会回退到 npm。
